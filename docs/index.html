Chat with a stranger for two minutes. It might be another player. It might be an LLM on Databricks pretending to be a sleep-deprived CS student. Then you decide.

Play now Run it in your workspace

No sign-up. The impostor runs on Databricks Model Serving, and every round is logged to Unity Catalog.

How a round works

  1. 01

    Get matched

    You join a queue. If another player is waiting you may get them; otherwise you get the AI. Every match takes 3 to 9 seconds either way, so the wait gives nothing away.

  2. 02

    Chat for two minutes

    Ask anything. The AI plays one of four personas with a backstory, a texting style, typing delays, and the occasional typo. It can even end the chat early, just like a person can.

  3. 03

    Make the call

    Human or AI? Correct guesses score 100 points plus a streak bonus. Against another human, you also score by seeming human yourself.

Everything runs on Databricks

Each round becomes data. That data trains a model that tries to beat the players at spotting the impostor.

Databricks Apps

The game

FastAPI backend and a no-build chat UI, deployed with one Asset Bundle command. Matchmaking, timers and scoring live in the app.

Model Serving

The impostor

Foundation Model API chat endpoint, prompted to stay in character and "humanized" after every reply.

Unity Catalog

Every word logged

Games, messages and guesses land in Delta tables through a SQL warehouse, using parameterized SQL and insert-only grants.

AI/BI-ready views

Who gets fooled

Detection accuracy, fool rate per persona, accuracy vs. chat length, and how AI and human texting styles differ.

MLflow + UC model registry

Model vs. humans

A text classifier learns the "AI tells" from every message, gets registered in Unity Catalog, and is scored against the players on the same held-out games. An hourly Job retrains it as more rounds come in.

Run it in your workspace

Works on Databricks Free Edition. You need the Databricks CLI and a SQL warehouse ID.

  1. git clone https://github.com/Hussam-Mak/ai-impostor.git && cd ai-impostor
  2. databricks bundle deploy --var warehouse_id=<id>
  3. databricks bundle run impostor_setup --var warehouse_id=<id>
  4. databricks bundle run ai_impostor --var warehouse_id=<id>

Full setup, settings and local offline mode are in the README.
